# Надпрофессиональные компетенции современного специалиста 🚀
## Интерактивный конструктор резюме

Лендинг-конструктор резюме, созданный специально для студентов и участников занятий по дисциплине **«Надпрофессиональные компетенции современного специалиста»**.

Сервис позволяет быстро структурировать свой профессиональный опыт, подчеркнуть ключевые гибкие и жесткие навыки по выбранной специальности, зафиксировать оцифрованные достижения и в **1 клик скачать привлекательную картинку резюме в формате `.jpg`**.

---

## 🌟 Ключевые возможности

1. **Контакты и информация о себе**:
   - Имя, желаемая позиция, контакты (Email, телефон, Telegram, город, портфолио/LinkedIn).
   - Загрузка личного фото/аватарки (с генерацией красивых инициалов в качестве фоллбека).
   - Профессиональное кредо и блок «О себе» с акцентом на личные сильные стороны.

2. **Опыт работы**:
   - Динамическое добавление/удаление мест работы.
   - Должность, компания, период и структурированное описание задач и командного влияния.

3. **Образование**:
   - Учебное заведение, специальность/степень и период обучения.

4. **Гибкие навыки (Soft Skills) — надпрофессиональный фундамент**:
   - Интерактивная библиотека готовых навыков в 1 клик:
     * *Эмоциональный интеллект*
     * *Ассертивная коммуникация*
     * *Критическое мышление*
     * *Управление конфликтами*
     * *Фасилитация и модерация*
     * *Кросс-функциональное лидерство*
     * *Адаптивность к изменениям*
     * *Наставничество и менторинг*
     * *Принятие решений в неопределенности*
     * *Тайм-менеджмент и фокус*
     * *Переговоры win-win*
   - Возможность добавления собственных уникальных навыков через поле ввода.

5. **Жесткие навыки (Hard Skills) по 8 направлениям подготовки**:
   Студент сначала выбирает свою специальность, после чего открывается готовая база специализированных навыков:
   1. **Юристы** (экспертиза договоров, анализ НПА, исковая работа, КонсультантПлюс/Гарант, судебное представительство)
   2. **Пожарная безопасность** (расчет рисков, ПТВ, АПС/СОУЭ, нормы ФЗ №123, планы эвакуации, СИЗОД)
   3. **Защита в ЧС** (АСР, первая помощь, инструмент ГАСИ, разведка ВПХР/ДП-5, СИЗ, ПВР, топография и радиосвязь)
   4. **Правоохранительная деятельность** (квалификация нарушений, протоколы, осмотр места происшествия, криминалистика, спецсредства)
   5. **Механики** (чертежи и схемы, диагностика и ТО оборудования, инструмент, допуски и посадки, КОМПАС-3D)
   6. **Электрики** (однолинейные схемы, электроустановки до 1000В, щиты ВРУ/ШУ, ПУЭ/ПТЭЭП, группа допуска)
   7. **Операторы АСУ** (SCADA-системы, контроллеры ПЛК/PLC, протоколы Modbus/Profibus, датчики КИПиА, HMI-панели)
   8. **Диспетчера (ЧС)** (Система-112, маршрутизация служб 01-04, ПО ЕДДС, стрессовый опрос, радио- и телефонная связь)
   - Возможность добавления любых собственных инструментов и навыков!

6. **Достижения и оцифрованные результаты**:
   - Специальный блок с подсказкой тренерской формулы: `[Действие] + [Soft Skill] + [Результат в % или цифрах]`.

7. **Дополнительно**:
   - Иностранные языки с указанием уровня (A1–C2).
   - Пройденные курсы и тренинги.

8. **Стили и оформление**:
   - 4 гармоничные дизайнерские темы:
     * 👔 **Executive Navy** (классический глубокий индиго / графит)
     * 🌲 **Emerald Leader** (изумрудный / лесной)
     * ☕ **Warm Editorial** (теплый терракотовый / кофейный)
     * ⚪ **Nordic Minimal** (скандинавский минимализм / монохром)

9. **Скачивание в 1 клик (High-Res JPG)**:
   - Генерация ультрачеткого JPG изображения стандартных пропорций **A4** (масштаб 2.5x для идеальной читаемости шрифтов при отправке в Telegram, почту или эйчарам).

10. **100% приватность и надежность**:
    - **Никаких баз данных и серверов**. Все вычисления и генерация происходят строго в браузере пользователя.
    - Никакой регистрации и паролей — ученики сразу приступают к практике.

## 📁 Структура проекта

```text
├── index.html           # Разметка лендинга, формы и A4-макета резюме
├── styles.css           # Современные CSS-стили, адаптивная сетка и цветовые темы
├── app.js               # Реактивное обновление макета, валидация и экспорт JPG
├── html2canvas.min.js   # Локальный бандл библиотеки рендеринга (без внешних зависимостей)
├── server.js            # Легковесный локальный Node.js сервер для разработки
└── package.json         # Манифест проекта и скрипты
```

## 💻 Локальный запуск

Для проверки или доработки проекта локально:

```bash
# 1. Запуск через Node.js:
npm start

# Или запуск через встроенный скрипт:
node server.js
```

Откройте в браузере: `http://localhost:3000`.

*Примечание: сайт полностью статичен, поэтому вы также можете просто открыть файл `index.html` в любом современном браузере.*

## ☁️ Развертывание на Cloudflare Pages

Проект идеально подходит для хостинга **Cloudflare Pages** (работает бесплатно, мгновенно отдает статику с CDN по всему миру).

### Вариант 1: Через GitHub / GitLab (Рекомендуемый)

1. Загрузите код в репозиторий GitHub.
2. Перейдите в панель [Cloudflare Dashboard](https://dash.cloudflare.com/) -> **Compute (Workers & Pages)** -> **Create application** -> **Pages** -> **Connect to Git**.
3. Выберите репозиторий.
4. В настройках сборки (Build settings):
   - **Framework preset**: `None`
   - **Build command**: оставьте пустым (или `echo ready`)
   - **Build output directory**: `/` (корень проекта)
5. Нажмите **Save and Deploy**. Ваш сайт станет доступен по адресу вида `https://<project-name>.pages.dev`.

### Вариант 2: Прямая загрузка файлов (Direct Upload без Git)

1. В Cloudflare Dashboard перейдите в **Pages** -> **Create application** -> **Pages** -> вкладка **Direct Upload**.
2. Укажите имя проекта.
3. Перетащите папку с файлами (`index.html`, `styles.css`, `app.js`, `html2canvas.min.js`) прямо в окно браузера.
4. Нажмите **Deploy site** — лендинг развернется за несколько секунд!

### Вариант 3: Через Wrangler CLI

```bash
npx wrangler pages deploy . --project-name=softskills-resume
```
